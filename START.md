# 🚀 COMECE AGORA - Wellness App v2

---

## **PASSO 1: Abra o Terminal/CMD**

```bash
cd wellness-app-v2
```

---

## **PASSO 2: Instale as dependências**

```bash
npm install
```

(Primeira vez leva uns 2-3 min)

---

## **PASSO 3: Rode o app**

```bash
npm run dev
```

---

## **PASSO 4: Abra no navegador**

Aparecerá uma mensagem tipo:
```
VITE v4.3.0 ready in 123 ms

➜  Local:   http://localhost:5173/
```

Clica no link ou digita no navegador.
